# ⚽ Football Manager Web App

Професійний веб-застосунок для керування футбольними командами, гравцями та автоматичного розрахунку турнірних таблиць. Проект розгорнуто на платформі Render.

## 🚀 Стек технологій
* **Backend:** Python 3.x, Django 6.x
* **Database:** PostgreSQL (на Render), SQLite (локально)
* **ORM:** Django ORM з використанням складних анотацій та агрегацій
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Deployment:** Render, Gunicorn, WhiteNoise

## 🛠️ Основні функції
- **Керування командами:** Створення, редагування та видалення футбольних клубів.
- **Склад гравців:** Можливість додавати гравців до кожної команди з прив'язкою через ForeignKey.
- **Менеджмент матчів:** Створення розкладу матчів із зазначенням рахунку.
- **Динамічна турнірна таблиця:** - Реалізована на базі Class-Based Views (`ListView`).
  - Розрахунок очок (В=3, Н=1, П=0) відбувається "на льоту" через агрегацію бази даних.
  - Автоматичне ігнорування незіграних матчів (де рахунок `NULL`).
- **Авторизація:** Доступ до редагування команд та гравців мають тільки зареєстровані менеджери.


## 📋 Налаштування та встановлення (локально)

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/Surftrader/football.git
   cd football
   ```  
2. **Створіть віртуальне оточення:**  
   ```bash  
   python -m venv venv
   source venv/bin/activate  # для macOS/Linux
   # venv\Scripts\activate  # для Windows
   ```  
3. **Встановіть залежності:**  
   ```bash
   pip install -r requirements.txt
   ```
4. **Запустіть міграції:**  
   ```bash  
   python manage.py migrate  
   ```
5. **Налаштування змінних оточення (.env)**  
 - Створіть файл `.env` у кореневій директорії проекту.  
 - Додайте в нього наступні параметри (приклад з файлу `.env.example`):  
   ```bash  
   SECRET_KEY='ваш_дуже_секретний_ключ'  
   DEBUG=True
   ALLOWED_HOSTS='localhost,127.0.0.1'
   ```  
6. **Створення суперкористувача (Адміністратора):**  
 - Виконайте команду в терміналі:  
   ```bash
   python manage.py createsuperuser
   ```  
 - Вкажіть ім'я користувача, email та пароль.  
 - Після запуску сервера (`python manage.py runserver`) адмін-панель буде доступна за адресою: `http://127.0.0.1:8000/admin/`  
7. **Запустіть сервер:**  
   ```bash
   python manage.py runserver
   ``` 
8. **Відкрийте сайт(локально)**  
 - Перейдіть за посиланням: [http://127.0.0.1:8000](http://127.0.0.1:8000)
